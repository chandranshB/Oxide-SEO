# Security Policy

## Supported Versions

Security updates are provided for the latest minor version of Oxide SEO.

| Version | Supported |
| ------- | --------- |
| 0.4.x   | Yes       |
| < 0.4.0 | No        |

## Reporting a Vulnerability

We take the security and privacy of Oxide SEO seriously. If you discover a security vulnerability or sensitive data issue:

1. **Do not create a public issue** on GitHub.
2. Please disclose the vulnerability privately via GitHub's [Private Vulnerability Reporting](https://github.com/chandranshB/Oxide-SEO/security/advisories/new) or by reaching out directly to the maintainer via GitHub profile contact.
3. Include detailed steps to reproduce the issue, along with proof-of-concept payloads or code where applicable.

### What to Expect
- You will receive an acknowledgment of your report within 48 hours.
- A status update will be provided once the vulnerability is validated and a fix is being engineered.
- Upon release of the patch, appropriate credit will be acknowledged in the release notes (unless you prefer anonymity).
