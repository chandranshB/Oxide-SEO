Oxide-SEO features a custom-built, highly concurrent Rust web crawler. 

## Starting an Audit

1. Go to the **Site Audit** tab.
2. Enter the target domain.
3. Configure the concurrent threads and crawl depth.
4. Click **Start Crawl**.

## What We Check
- **Status Codes**: 404s, 500s, redirect chains.
- **On-Page Elements**: Missing H1s, duplicate titles, meta descriptions.
- **Performance**: Time to First Byte (TTFB) and asset sizes.
