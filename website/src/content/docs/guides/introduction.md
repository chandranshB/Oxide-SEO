Welcome to Oxide-SEO, the ultimate standalone desktop application for technical SEO audits, keyword research, and GSC data analysis.

## Why a Desktop App?

Most SEO tools are cloud-based, charging you hefty monthly subscriptions while owning your data. Oxide-SEO takes a different approach:
- **Local First**: All data is stored in your local SQLite databases.
- **Fast**: Built with a Rust backend (Tauri) for lightning-fast crawls and API operations.
- **Private**: No data leakage. Your clients' search console data never touches our servers.

Get ready to supercharge your technical SEO workflow.
